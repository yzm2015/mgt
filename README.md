# 磁吸拆迁队 V10 · 霓虹磁场行动

根据名字重新设计的微信小游戏：驾驶磁吸回收车，吸走承重点，让建筑倒塌，把废铁拖回回收站赚钱升级。

## 试玩与运行

- 运行 `npm start`，访问 http://127.0.0.1:8766 。没有第三方依赖，不需要 npm install。
- 微信开发者工具导入本项目目录，现有 AppID 已保留，工程类型为小游戏。微信小游戏是微信内游戏的运行形式，不是普通表单类小程序页面。
- `npm test`：验证磁吸、材料守恒、载重、完整通关、奖励只发一次、升级持久化、每日统一车辆和后台暂停。

## 操作

在工地区域按住并拖动，车辆朝手指移动，松手停车。靠近橙色锚点自动吸取，圆形进度转满后拔除。建筑三处锚点全部拔除就会倒塌，变成可回收废铁。靠近废铁自动吸到车后拖链，载重满后驶入左下角绿色回收站自动卸货。

右下角“电磁脉冲”瞬间击穿 148 范围内的核心，并提供 5 秒超频；坍塌冲击波还能削弱 170 范围内其他建筑的核心，连续击破在 4 秒内叠加评分倍率。能量自动缓慢恢复，回收 20 件可从零充满。左下角“无人机回收”远程交付车尾货物，16 秒冷却，可与地面回收站搭配使用。拆完三栋建筑，并交付当前工地要求的材料比例（70%～86%），即完成委托。普通工地基础结算为回收数量 + 30 币，另有首通、升星及连击奖励，车库可升级磁力和载重，每项最多 5 级。每日同题使用统一初始车辆，记录本机当天最快时间；登录后开局并完成可上传每日休闲榜，不给可重复刷取的奖励。

## 结构

- `src/salvage-core.js`：移动、碰撞、锚点提取、倒塌、磁吸、卸货、暴走、随机数和存档验证。
- `src/neo-art.js`：程序绘制的霓虹机甲、立体能量塔、磁场和扫描场景。
- `src/salvage-app.js`：首页、游戏、结算、暂停、车库、统一触摸交互和绘制。
- `game.js`：微信平台适配，存储、分享、触觉反馈、生命周期、安全区。
- `test.html`：浏览器试玩适配；`server.js` 只允许访问明确列出的试玩资源，不提供仓库和私钥下载。
- `GAME_DESIGN.md`：本版设计与边界；`VALIDATION_PLAN.md`：玩家测试与上线验证。

本版存档键为 `magnet-crew-v5`，不覆盖旧版进度。旧 V3 主入口备份为 `legacy/game-v3.js`，恢复时须复制回根目录；上一次 V4 原型也保留在 `legacy` 与旧 `src/core.js`、`src/app.js` 中。旧代码、文档、浏览器文件、测试不会进入微信上传包。

## V7 本轮新增

首塔拆除后提供三选一战术模组（仅普通任务）；选择期间暂停计时，只可领取一次。电弧共振增强脉冲和坍塌链，回收蜂群提升载重并缩短无人机冷却，矢量超驱提高移动、磁吸和充能。新增 4 秒冷却的短距推进，沿当前朝向突进，保留建筑碰撞与边界限制。地图扩为三种基础阵列，后续关卡由种子选择阵列。完成 6 连击额外奖励 25 回收币。

## V9.3 成长与危险合约

通关获得回收币、经验和科技零件。首通与首次升星奖励只发一次；重复通关仍给基础收入与经验，危险合约可重复获得零件。工程师每升一级额外获得 2 零件，最高 LV.20。旧存档自动补零值，不覆盖已有磁力、载重或关卡记录，不追溯发放旧通关的首通奖励。

机库现有磁力、载重、引擎、反应堆、空运五条科技线，各 5 级。后三项升级消耗回收币和科技零件，分别提升移动与推进、脉冲与充能、无人机冷却。先锋底盘默认开放，蜂群底盘 LV.2 开放，闪电底盘 LV.4 开放；解锁后免费切换。

每座已通关工地可在航图点选后开启危险合约：核心装甲 ×1.4，移动电磁风暴每 9 秒中激活 4 秒，进入风暴移速降低 35%、磁吸范围减少 18。危险合约基础币 ×1.5、经验额外 +25、零件额外 +1。不会引入死亡惩罚或体力门槛。

首页主图右下角进入每日委托，完成普通工地、金属回收和连击目标后手动领奖；每项每天一次，按北京时间更新。普通与危险合约都计入，竞速不计入。领奖及升级写入失败会回退，本局结算保存失败可在结算页点状态重试，不重复发奖励。

每日竞速保留标准车辆，不继承装备、底盘或危险合约条件。成长依然是本机进度加手动云备份，未升级为防作弊服务端经济。

43 项测试通过，16 种标准/危险工地组合的零升级真实移动模拟通关；新版机库与委托已截图检查。V9.3.0 于 2026-10-15 由“小明大爱”通过官方 CLI 上传为开发版本（65,247 字节），未提审或发布；手机实机性能仍待验收。

## V10 当前版本：WebGL 3D 与关卡主线

游戏工地使用原生 WebGL 真实三维网格、逐顶点定向光照、深度测试和正交相机；建筑、车辆、物料、任务装置、坍塌碎块均为 3D 几何。界面仍用 2D HUD，经纹理合成到主 WebGL 画布。点击画面上方左右镜头按钮旋转 45°，回转按钮复位，触摸坐标通过相机反投影映射到地面。没有第三方引擎和远程模型依赖。

每关必须同时满足：三栋建筑倒塌完成、材料交付配额达标、本关主线完成。原支线与时间目标仍影响星章，不替代主线。点击绿色主线可随时查看暂停计时的作战简报。

新增 src/scene3d.js（WebGL 渲染、相机、地面拾取）与 src/missions.js（独立关卡主线）。没有 WebGL 时明确显示兼容视图。三维表现共享原地面平面碰撞与移动模拟，不包含完整三维刚体物理；接触暗影为简化几何，未采用阴影贴图。
